- **結果**：APIによる測定結果は未記入。本人の `GEMINI_API_KEY` を設定した環境で実行後、CSVの数値・回答内容を転記する。
- **気づき・疑問**：APIが返す出力トークン数（`candidates_token_count`）と合計トークン数（`total_token_count`）は異なる場合があるため、両方を区別して記録する。応答時間にはネットワーク通信やサーバーの負荷も含まれるため、1回の測定だけでモデル性能を断定できない。

### 実行方法

```bash
uv run python -m app.compare_models \
  --models gemini-3.5-flash-lite gemini-3.6-flash \
  --trials 1 --delay 3 \
  --output results/lec01-comparison.csv
```

実行後は `results/lec01-comparison.csv` の各行を比較する。必要なら `--trials 3` で繰り返し測定する（呼び出し回数はモデル数×質問数×試行回数）。
