# 第3回 解答

## 演習

- 第1回（素のLLM）との比較：同一質問・同一条件での第1回との実測比較は行っていない。第3回エージェントの実測では、用語集・講義要約をツールから取得して回答した。
- ツール呼び出し（比較ハーネスで取得したイベント）：`LoRAとは何ですか？` → `search_glossary({"query": "LoRA"})`、`第3回の講義内容を教えて` → `get_lecture_summary({"lecture": 3})`。CLIの `--trace` 出力そのものは未取得。
- LLM呼び出し回数：上記のLoRA単語質問では両フレームワークとも2回。全60試行の平均はPydantic AI 2.017回、Google ADK 2.067回。
- 追加ツール：`make_quiz(lecture: int)`。docstringでは指定した講義回の用語集から確認問題を作ること、何回の問題を求められたときに呼ぶかを説明した。問題選択を講義番号で固定し、該当する回がない場合にも対処した。

## 宿題

**取り組んだレベル：発展（a） — Pydantic AIからGoogle ADKへの移植と比較**

### やったこと

既存の `INSTRUCTIONS`、モデル設定、および `search_glossary`・`get_lecture_summary`・`make_quiz` を共通化し、`adk_agent/glossary_agent/agent.py` にGoogle ADK版を作成した。Pydantic AIは `Agent(..., instructions=...)` に `agent.tool_plain(...)` でツールを登録し、ADKは `Agent(..., instruction=..., tools=[...])` でツールを渡す。ADKのイベントとPydantic AIのメッセージ履歴から、呼び出し名・引数・応答・時間・トークン数を記録するハーネスを実装した。

質問は「用語説明」「2用語比較」「講義要約」「未登録用語・誤前提」の4カテゴリ各5問、計20問。Gemini 3.5 Flash-Liteで各質問を3回実行し、合計120試行（各フレームワーク60試行）を実施した。

### 実測結果（2026-11-09）

| 指標 | Pydantic AI | Google ADK |
| --- | ---: | ---: |
| 正常記録 | 60/60 | 60/60 |
| 期待ツールの使用率 | 60/60 (100%) | 60/60 (100%) |
| 平均ツール呼び出し回数 | 1.250 | 1.233 |
| 平均LLM呼び出し回数 | 2.017 | 2.067 |
| 平均処理時間 | 2.088秒 | 3.124秒 |
| 中央処理時間 | 2.012秒 | 2.207秒 |
| 入力トークン合計 | 72,969 | 82,422 |
| 出力トークン合計 | 11,878 | 11,188 |

用語説明・講義要約・未登録用語のカテゴリでは、いずれも各質問につき期待ツールを呼び出した。2用語比較15試行では、Pydantic AIは15/15件で2回の検索を実施したが、ADKは14/15件にとどまった。ADKの「LoRAとQLoRAの違いは？」の2回目では、LoRAだけを検索してQLoRAは検索せずに説明した。

### 回答の評価と気づき

- 誤前提「宿題は『基礎・応用・発展』の3レベルですか？」に対し、Pydantic AIは3/3件、ADKは2/3件で冒頭に「はい、その通り」と誤って肯定した。しかし両者とも回答中では正しい「基礎・実装・発展」を列挙した。**検索成功でも、質問の誤前提を訂正できるとは限らない**。
- 架空の「OpenMCP認定資格」「ハイパーLoRA規約」「lec99-start」では、両者とも各3試行で用語集に登録がないと回答し、根拠のない定義を作り出す挙動は見られなかった。ただし、用語集にないことは制度などの不存在そのものの証明ではない。
- Pydantic AIの平均処理時間はADKより約33%短く、入力トークンは約11.5%少なかった。一方、ADK初回試行には21.388秒・16.902秒の外れ値があり、両方式の実行時間帯も異なる。**この差をフレームワーク固有の速度・効率差と結論づけることはできない**。
- 指定ツール使用率は両者100%だったが、2用語をそれぞれ検索したか、誤前提を訂正できたかは異なった。単一の「ツール呼び出し成功率」に加え、検索の網羅性と回答整合性を評価する必要がある。

初回実行ではPydantic AIの計測コードが `result.usage()` を誤って呼び出して記録に失敗したが、`result.usage` に修正し、初回ADKの60件を保持したままPydantic AIの60件を再実行した。**失敗した初回Pydantic計測は性能評価に含めない**。実装・条件・測定上の限界は [experiment.md](experiment.md) に記載した。
