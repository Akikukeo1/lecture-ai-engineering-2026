## 宿題：発展（a）

Pydantic AIと同じ指示・モデル・ツールを使ってGoogle ADK版を実装した。ツールの登録は、Pydantic AIでは `agent.tool_plain()`、ADKでは `Agent(tools=[...])` を使う。

Gemini 3.5 Flash-Liteで、用語説明・2用語比較・講義要約・未登録用語や誤前提の各5問を3回ずつ実行した（20問×3回×2方式＝120試行）。`scripts/compare_agent_frameworks.py` で回答、ツール呼び出し、処理時間、トークン数を記録した。

| 指標 | Pydantic AI | Google ADK |
| --- | ---: | ---: |
| 正常記録 | 60/60 | 60/60 |
| 指定ツール使用率 | 100% | 100% |
| 平均ツール呼び出し | 1.250回 | 1.233回 |
| 平均LLM呼び出し | 2.017回 | 2.067回 |
| 平均処理時間 | 2.088秒 | 3.124秒 |
| 処理時間の中央値 | 2.012秒 | 2.207秒 |
| 入力トークン合計 | 72,969 | 82,422 |
| 出力トークン合計 | 11,878 | 11,188 |

2用語比較で両方を個別検索したのはPydantic AIが15/15件、ADKが14/15件。「宿題は基礎・応用・発展の3段階か」という誤前提には、それぞれ3/3件、2/3件で誤って肯定しながら、本文では正しい「基礎・実装・発展」を列挙した。架空の3用語については、両者とも用語集にないと回答した。

**ツール使用率だけでは検索の網羅性や回答の整合性を測れない。** 処理時間はPydantic AIの方が短かったが、初回の遅延と測定時間帯の差があるため、フレームワーク固有の性能差とは判断できない。

初回はPydantic AI側の計測コードの `result.usage()` が原因で記録に失敗した。修正後にPydantic AIだけ再実行し、ADKの60試行と合わせて集計した。回答の全件正誤判定は行っていない。

実行コマンド：

```bash
PYTHONPATH=. uv run --with 'google-adk>=2,<3' python -m scripts.compare_agent_frameworks
```
