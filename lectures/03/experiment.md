# Pydantic AIとGoogle ADKの比較実験

## 方法

同じ指示（`INSTRUCTIONS`）、Gemini 3.5 Flash-Lite、3つのツール（`search_glossary`、`get_lecture_summary`、`make_quiz`）を使用。用語説明・2用語比較・講義要約・未登録用語や誤前提の各5問を3回ずつ、計120試行実行した。

`scripts/compare_agent_frameworks.py` で回答、ツール呼び出し、LLM呼び出し回数、処理時間、トークン数を記録した。

```bash
PYTHONPATH=. uv run --with 'google-adk>=2,<3' python -m scripts.compare_agent_frameworks
```

## 結果（2026年11月9日）

| 指標 | Pydantic AI | Google ADK |
| --- | ---: | ---: |
| 正常記録 | 60/60 | 60/60 |
| 指定ツール使用率 | 100% | 100% |
| 平均ツール呼び出し | 1.250回 | 1.233回 |
| 平均LLM呼び出し | 2.017回 | 2.067回 |
| 平均処理時間 | 2.088秒 | 3.124秒 |
| 処理時間の中央値 | 2.012秒 | 2.207秒 |
| 入力トークン合計 | 72,969 | 82,422 |
| 出力トークン合計 | 11,878 | 11,188 |

- **検索の網羅性**：2用語比較15試行のうち、両語を個別検索したのはPydantic AIが15件、ADKが14件。ADKは1回だけLoRAを検索し、QLoRAは検索せずに説明した。
- **誤前提**：「宿題は基礎・応用・発展の3段階か」への誤肯定はPydantic AIが3/3件、ADKが2/3件。両者とも回答内に正しい「基礎・実装・発展」も記載していた。
- **未登録用語**：「OpenMCP認定資格」「ハイパーLoRA規約」「lec99-start」は、両者とも用語集にないと回答した。

## 考察

指定ツール使用率は同じ100%でも、検索の網羅性と回答の整合性には差があった。ツール使用率だけでは回答品質を測れない。

Pydantic AIの平均処理時間は短かったが、ADKには初回の遅い試行が含まれ、測定時間帯も異なる。フレームワーク固有の速度差とは判断できない。

初回は計測コードの `result.usage()` が原因でPydantic AIの記録に失敗した。修正後にPydantic AIの60件だけ再実行し、ADKの初回60件と合わせて集計した。回答の全件正誤判定は行っていない。
